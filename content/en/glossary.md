## A

### Advisory

Advisory services help clients navigate available cloud services and use them effectively, providing expert guidance without provisioning or managing infrastructure on the client's behalf.

## C

### Cloud environment

A cloud environment refers to the cloud resources provisioned for a client, such as an Azure subscription, an AWS account, or a GCP project.

### Cost-recovery

A cost-recovery basis means a service is billed to clients to cover its costs (for example, against a defined number of hours at an hourly rate), rather than being centrally funded.

## H

### High-Performance Computing (HPC)

High-Performance Computing (HPC) refers to dedicated infrastructure designed for large-scale, sustained computing workloads, distinct from the short-term compute capacity offered by services like PIE.

## S

### Sandbox

A sandbox is an isolated cloud environment provided to clients for experimentation, separate from a dedicated Advisory engagement.

### Subscription

A subscription is the billing and resource container used in Microsoft Azure to organize and manage cloud resources.

## T

### Tenant

A tenant is an organization's dedicated instance of Microsoft Entra ID (Azure Active Directory), used to manage identity and access for its cloud resources.
